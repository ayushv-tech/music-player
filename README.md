# 🎵 Music Player

A stylish Music Player built using HTML, CSS, and JavaScript.

## 🚀 Features

- ▶️ Play / Pause Music
- ⏭️ Next Button
- ⏮️ Previous Button
- 🔊 Volume Control
- 📊 Progress Bar
- 🎨 Stylish UI Design
- 🎵 Music Cover Image
- ⚡ Responsive Layout

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Font Awesome Icons
